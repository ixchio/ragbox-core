## Previous Results (v2.1.1 — pre-GraphRAG fix)

These results were from the original implementation where the knowledge graph
had placeholder query logic. They are included for transparency.

| Category | RAGBox v2.1.1 | Vanilla | Winner |
|---|---|---|---|
| **Overall** | 0.529 | 0.779 | Vanilla |
| **Factual** (simple lookup) | 0.738 | 0.765 | Vanilla |
| **Relationship** (cross-doc) | 0.727 | 0.832 | Vanilla |
| **Multi-Hop** (3+ docs) | 0.123 | 0.739 | Vanilla |

**Root cause of multi-hop failures**: The knowledge graph `query()` method returned
placeholder community summaries instead of real entity context. Four multi-hop
queries scored 0.000 because the graph path provided no useful information.

## What Changed (v3.0.0)

The following architectural improvements target the root causes:

1. **Real graph query** — Entity matching via fuzzy/token overlap + description matching,
   2-hop graph traversal, actual entity source texts and relationship context returned
2. **Community summarization** — LLM-generated summaries for each Leiden community
3. **Multi-hop decomposition** — Complex queries are split into atomic sub-queries,
   retrieved independently, and synthesized
4. **Graph+Vector fusion** — Graph context is injected as separate RRF candidates
   alongside vector results, not as a replacement
5. **Recursive semantic chunking** — Paragraph → sentence → word boundary splitting
   (replaces LLM-scored chunking which burned tokens for no benefit)
6. **Context-enriched embeddings** — Sliding window context (honestly named,
   not "late chunking")

> **Note**: Benchmarks need to be re-run with the v3.0.0 architecture.

## Architecture

RAGBox now features true Dual-Mode Retrieval:

- **Fast Path (Factual):** Heuristic-classified simple queries bypass the graph and
  reranker entirely. Direct top-k vector search. Latency: ~50-150ms.
- **Deep Path (GraphRAG + Multi-hop):** Complex queries activate the full pipeline:
  entity matching → graph traversal → community summaries → RRF fusion with vector
  results → cross-encoder reranking → synthesis prompt.

## Methodology

- **Corpus**: 8 interconnected documents with shared entities and relationships
- **Questions**: 15 total — 5 factual, 5 relationship, 5 multi-hop
- **Scoring**: Sentence-Transformer (`all-MiniLM-L6-v2`) cosine similarity
- **GraphRAG**: Real LLM entity extraction with caching
- **Backend**: Groq (llama-3 / mixtral) — free tier
